# Serhii Tanichev

DevOps and SRE engineer with ten years of production SaaS behind me, and the creator of [Email Spam Tester](https://email-spam-tester.com/). I run mail infrastructure for a living, and the tester grew out of the checks I kept doing by hand.

Email Spam Tester is a free, independent email deliverability testing tool. You send one message to a disposable address and get 41 checks back, from SPF, DKIM and DMARC alignment to blocklists, two spam engines and the Gmail and Yahoo bulk sender rules, with every warning quoting the RFC section it rests on. Started in 2026, currently free, no signup.
